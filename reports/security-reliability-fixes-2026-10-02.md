## 逐项处理结果

| 问题 | 当前实现 | 验证 |
|---|---|---|
| 代理/隧道被当成内网管理员 | 同进程新增严格公网入口，任何来源都不能凭 IP 获得管理权限；可信转发链从右向左处理 | 双入口 HTTP 回归；随包 Python 实际 main 启动；真实浏览器登录 |
| 访问码撤销与明文清单暴露 | 更换/禁用访问码撤销相关会话；每次请求检查项目有效性；静态访问只允许查看器使用的 processed 文件 | 旧会话立即 401；原始清单及路径变体拒绝；模型仍可读取 |
| 未鉴权请求体消耗内存/连接 | 路由鉴权先于读取；JSON/上传大小限制；上传流式落盘；绝对请求头/请求体期限；连接数量限制 | 大体积声明提前拒绝、截断、滴流、重复 Content-Length、Transfer-Encoding、连接槽释放 |
| 跨站写入 | 写请求要求专用请求头；校验 Origin、Fetch Metadata、JSON 类型；管理入口校验 Host | HTTP 攻击变体拒绝；真实 api.js/XHR 写入正常 |
| 重复导入及同版本竞争 | 原子状态转换、版本预留；只有 queued 可启动；失败/中断走显式 retry；前端清理未启动任务 | 15 个隔离导入用例；真实两种转换链 |
| 导入期间删除/改名竞争 | 仓库与后台提交共享锁；活动导入阻止删除；最终提交保留最新改名 | Project/Model/Version 三层删除、ready/failed 改名竞争验证 |
| 异步切换版本混用数据 | 请求代次、取消信号贯穿元数据、GLB、叠加和分屏；过期资源释放；批注绑定固定上下文 | 慢元数据/GLB切换与比较取消测试 |
| 错误提示执行版本名中的脚本 | 动态错误信息改用文本 DOM | Chromium 中恶意名称不执行 |
| normalized/structure 映射自相矛盾 | key 使用 TXT canonical，sourceName 保留几何原名；校验通道证据、父/类型/序号、唯一性与字节锚点 | 19 个映射用例；现有 18,984 条 exact 技术锚点保持一致 |
| GLB 校验无效平方扫描 | 删除结果会被覆盖的第一次根计算，保留集合算法 | 前后完整分析输出相等；合成规模基准 |
| 隐藏查看器仍持续绘制 | 选择器/文档不可见时暂停帧循环，恢复时重新绘制，模型保留 | 隐藏后帧计数停止、恢复后继续 |
| 选中/预选中触发全模型合批扫描 | canonical→entry 索引、变化差集、最多 32 MiB 世界几何缓存；保留无缓存回退 | 256 网格夹具：首次预选中扫描 1 条，换对象扫描 2 条；显隐/隔离/Ghost/父子选中与拾取验证 |
| 分享脚本可能公开错误服务 | 先验证工作目录、同一实例 ID、严格入口和匿名身份，失败不启动隧道 | 正常及错误工作目录/实例/入口预检 |

附带边界修复：导入最多同时运行 2 个、未结束任务最多 32 个；转换阶段默认 30 分钟超时并终止子进程树；日志内存尾部限制；尊重转换校验器的失败退出码；登录按可信来源 IP 限流。

## 使用方式

- 日常使用仍运行 `start.bat` 或 `start-lan.bat`，本机/局域网继续免登录。
- 管理入口是 8765；公网回源是仅绑定本机的 8766，始终凭访问码只读。
- `share.bat` 只连接验证通过的 8766。运行旧后台时先关闭旧后台，再启动新版脚本。
- 不要将 8765 管理端口直接公开；两个入口由同一进程提供，避免多进程写入同一仓库。
- 真正上服务器时配置 HTTPS 代理、证书与防火墙，代理保留原始 Host。示例见 [README](../README.md)。

本次未部署服务器、未创建公网隧道，也未进行真实公网渗透。测试未修改现有项目的模型、批注或资料；现有权限配置仅更新过时注释，未更改密码和配置值。
